**보기 → https://sky970508-netizen.github.io/trans-card-viewer/**

| 분류 | 내용 |
|---|---|
| Community | 커뮤니티 지도 (인터랙티브) |
| Map | 읍면동 개별 choropleth — POI / 허브 × 수도권 / 서울 |
| Cartography | 커뮤니티 원형그래프 — POI / POI-LQ / hub |

날짜는 2026-06-22 ~ 06-28 (7일). 그림을 누르면 원본 크기로 확대되고,
`←` `→` 로 날짜, `1`~`9` 로 세부 항목을 바꾼다.
